## 一、核心代码

```python
def main():
    chat = Chat()
    while True:
        try:
            text = input("你> ").strip()
        except (KeyboardInterrupt, EOFError):
            chat.save(); print("\n再见！"); break
        if not text:
            continue
        parts = text.split(maxsplit=1)
        cmd = parts[0].lower()
        args = parts[1] if len(parts) > 1 else ""
        ...
```

主循环做 **四件事**：读输入、防崩溃、析命令、空输入过滤。

## 二、`split(maxsplit=1)`：为什么必须是 1

```python
"/doc load D:\\TanTian\\LLM\\笔记.md".split()
# ['/doc', 'load', 'D:\\TanTian\\LLM\\笔记.md']   ← 路径碎了

"/doc load D:\\TanTian\\LLM\\笔记.md".split(maxsplit=1)
# ['/doc', 'load D:\\TanTian\\LLM\\笔记.md']      ← 参数原样保留
```

**只要涉及带空格的路径或句子，就必须限制切分次数。** 这也是 shell 里路径要加引号的原因。

## 三、`.strip().lower()` 的顺序

先清洗格式（`strip`），再做语义转换（`lower`）。功能上两者互换无影响，但 `.strip().replace(" ", "")` 这类组合就有关系了。

> **固定习惯：清洗在前，转换在后。**

## 四、`input()` 为什么要包 try

`input()` 是阻塞调用。用户按 **Ctrl+C** 时抛 `KeyboardInterrupt`。不捕获的后果：

* 终端一堆红字
* 会话没保存就退出

捕获后 **干净退出 + 数据落盘**。`(KeyboardInterrupt, EOFError)` 元组写法 = 两种异常同一处理方式。`EOFError` 发生在管道输入或终端被强关时。

### 为什么 `KeyboardInterrupt` 不能被 `except Exception` 吞掉

```
BaseException
├── SystemExit
├── KeyboardInterrupt     ← 不在 Exception 下面！
└── Exception
```

`KeyboardInterrupt` 继承自 `BaseException`。所以 `except Exception` **抓不到它**，Ctrl+C 依然有效。

反过来：裸 `except:` 能抓到它 → 用户按 Ctrl+C 关不掉程序。**这就是"永远不用裸 except"的技术根源**，和第 2 周\_02 的异常树连上了。

## 五、空输入 continue

误触回车不当作一条消息塞进历史，否则模型对空字符串作答，**污染上下文**。

## 六、改进方向：命令注册表

if/elif 链命令一多就变长面条。表化后加新命令只需加函数，主循环一行不改——**这是 click/typer 的底层思路**。

```python
COMMANDS = {}
def command(name):
    def deco(fn): COMMANDS[name] = fn; return fn
    return deco

@command("/quit")
def do_quit(chat, args): raise SystemExit
```

## 七、破坏性实验记录

| 改动                    | 现象                    |
| --------------------- | --------------------- |
| 去掉 `strip()`          | `" /quit "` 匹配不上，命令失效 |
| 去掉 `maxsplit=1`       | 路径参数被切碎丢失             |
| `except Exception` 替代 | Ctrl+C 关不掉，只能杀进程      |

## 八、验收成果

* `/echo on|off` 回显开关正常，`/history` 仍可见全部记录
* 带空格的路径参数原样拿到
* Ctrl+C 干净退出并打印条数统计
* 能说清 `maxsplit=1` 作用、`KeyboardInterrupt` 为何不属于 `Exception`
