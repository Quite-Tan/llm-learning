## 六、已定下的编码约定（所有新代码照此执行）

1. 环境变量（`OLLAMA_HOST`、`NO_PROXY`）一律放在**所有第三方 import 之前**
2. 读小文本文件用 `Path.read_text(encoding="utf-8")`，不用 `open()`
3. `json.dump` 必须带 `ensure_ascii=False, indent=2, encoding="utf-8"`
4. 异常分层：具体异常 → `Exception` 兜底；**不用裸 `except:`**
5. 失败的消息必须从 history 里 `pop` 回滚，不能留半截
6. 可变对象（list/dict）**绝不写成类属性**，一律放 `__init__`
7. 无状态的工具函数用 `@staticmethod` 或提到类外
8. 流式输出必须 `end=""` + `flush=True`，且手动拼接 `full_reply` 落库
9. 外部文档硬塞必须设字符上限（当前 `MAX_DOC_CHARS = 8000`）
